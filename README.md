# Maternar(me) · Vuelve a ti

Sitio web de una sola página (HTML + CSS + JS, sin dependencias ni compilación).

- `index.html` – estructura y textos
- `assets/css/styles.css` – sistema visual (colores y tipografías del manual de marca)
- `assets/js/main.js` – menú, animaciones lentas, parallax suave y pausa de respiración
- `assets/img/` – ilustraciones y logos optimizados
